## 📖 Overview

Portfolio pribadi yang dirancang khusus untuk memamerkan keahlian di bidang **Frontend Development**, **Full-Stack Exploration**, dan **UI/UX Design**. Dibangun dengan pendekatan desain editorial modern (*Awwwards-level craft*), nuansa warna *warm espresso & amber glow*, efek 3D glassmorphic badges, serta animasi transisi berbasis *Framer Motion* dan *Lenis Smooth Scroll*.

## ✨ Key Features

- **⚡ Dynamic Hero Section**:
  - Foto profil berbingkai *ambient glow* dengan cincin orbit 3D yang berputar dinamis memuat lencana teknologi tegak.
  - Ilustrasi floating 3D (petir neon & glossy sphere) yang bereaksi halus terhadap tema gelap.
  - Micro-interactions kartu testimoni capstone project nyata.
- **💼 Selected Works & Case Studies**:
  - Showcase proyek unggulan (seperti **DIDISPEN**, **Smart**, **VoktaDev**, **Fintivity**).
  - Filter kategori interaktif (*All, Frontend, Full-Stack, UI/UX*).
  - Pratinjau editorial dengan tag teknologi terstandarisasi.
- **🪐 3D Illustrated Technology Stack**:
  - 11 kartu teknologi dengan lencana fisik 3D (*extruded pedestal base*, lempeng kaca cembung, pantulan *specular curved sheen*, serta logo melayang dengan dual drop-shadow).
  - Termasuk React, JavaScript, Tailwind CSS, Laravel, PHP, MySQL, MongoDB, Postman, VS Code, Figma, dan Git & GitHub.
- **🗺️ Journey & Career Timeline**:
  - Riwayat tahapan pembelajaran dari dasar algoritma pemrograman hingga fokus ke *production engineering*.
- **📐 5-Step Process Section**:
  - Metodologi kerja sistematis dari *Discover, Structure, Design, Build,* hingga *Polish & Test*.
- **📬 Responsive & Smooth UX**:
  - Didukung *Lenis Smooth Scrolling* untuk navigasi antar-seksi yang mulus.
  - 100% responsif dari layar smartphone hingga monitor desktop ultra-wide.

## 🚀 Getting Started

### Prasyarat
- [Node.js](https://nodejs.org/) versi 18.0 atau yang lebih baru
- `npm` atau `pnpm` / `yarn`

### Instalasi & Menjalankan Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/MaulanaFahriOktavian/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173/` pada browser Anda.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
   Output bundle yang siap di-deploy akan berada di direktori `dist/`.

```text
│   └── index.css          # Global styling & Tailwind directives

```
